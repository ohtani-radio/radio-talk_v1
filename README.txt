RADIO TALK - 更新方法

1. VS Codeで radio-talk-final フォルダを丸ごと開く
2. index.html を右クリックして Open with Live Server
3. 更新するファイル
   text/title.txt       テーマ名
   text/japanese.txt    日本語原稿
   text/vietnamese.txt  ベトナム語原稿
   text/indonesian.txt  インドネシア語原稿
4. 音声は audio フォルダに入れる
   japanese.m4a
   vietnamese.mp3
   indonesian.mp3

原稿の書き方
◆大見出し
■小見出し
・箇条書き
> 強調文

HTMLを編集する必要はありません。
